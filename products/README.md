# Products

This section contains per-product overviews, specifications, tips, and useful configurations for Actisense hardware.

---

> 📝 These pages are generic starting points. Each is accurate at a high level but
> intentionally light on hard specifications — contributions that add detail, images, and
> real-world tips are very welcome. See [CONTRIBUTING.md](../CONTRIBUTING.md).
>
> To add a new product page, copy [`_TEMPLATE.md`](./_TEMPLATE.md) and fill it in.

### NMEA 2000 Range

| Product | Description |
|---|---|
| [NGX-1](./ngx-1.md) | NMEA 2000 to PC gateway (Transfer) + NMEA 0183 ↔ NMEA 2000 converter (Convert) |
| [W2K-2](./w2k-2.md) | NMEA 2000 to Wi-Fi gateway |
| [WGX-1](./wgx-1.md) | NMEA 0183 + NMEA 2000 to Wi-Fi gateway |
| [EMU-1](./emu-1.md) | Engine monitoring unit (analogue → NMEA 2000) |

### NMEA 0183 Range

| Product | Description |
|---|---|
| [USG-2](./usg-2.md) | USB to serial (NMEA 0183) gateway |

### PRO Range

| Product | Description |
|---|---|
| [PRO-NDC-1E2K](./pro-ndc-1e2k.md) | Type-approved 0183 multiplexer + NMEA 2000 gateway |
| [PRO-NDC-1E](./pro-ndc-1e.md) | Type-approved intelligent NMEA 0183 multiplexer |
| [PRO-MUX-2](./pro-mux-2.md) | Type-approved intelligent NMEA 0183 multiplexer |
| [PRO-BUF-2](./pro-buf-2.md) | Type-approved intelligent NMEA buffer |
| [PRO-NBF-1](./pro-nbf-1.md) | Type-approved NMEA buffer |

### Legacy (still widely installed)

| Product | Description |
|---|---|
| [NGT-1](./ngt-1.md) | NMEA 2000 to PC gateway — superseded by NGX-1 |
| [NGW-1](./ngw-1.md) | NMEA 0183 ↔ NMEA 2000 converter — conversion role also offered by NGX-1 (Convert mode) |
| [W2K-1](./w2k-1.md) | NMEA 2000 to Wi-Fi gateway — superseded by W2K-2 |
| [NDC-4](./ndc-4.md) | NMEA 0183 multiplexer — superseded by the PRO range |
