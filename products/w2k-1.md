## Overview

The W2K-1 brought NMEA 2000 data onto Wi-Fi and Ethernet, allowing apps on phones, tablets,
and PCs to receive live vessel data wirelessly, with onboard SD card logging. It remains
widely installed. The [W2K-2](./w2k-2.md) is its current successor; much of the SD-card and
web-interface guidance is shared between the two.

## Key Features

- NMEA 2000 to Wi-Fi and Ethernet gateway
- Serves data to multiple clients
- Onboard SD card logging
- Built-in web interface

## Connections & Interfaces

- **NMEA 2000:** Micro-C drop connection to the backbone
- **Network:** Wi-Fi (access point / client) and Ethernet
- **Storage:** SD card slot — see [SD Card Guidance](../faq/faq-1.md)
- **Power:** Powered from the NMEA 2000 backbone.

## Getting Started

1. Connect the W2K-1 to a powered, terminated NMEA 2000 backbone.
2. Join its Wi-Fi network (or connect it to your onboard network) and open the web interface.
3. Configure output ports/formats for your app.
4. Confirm data is received.

## Software & Tools

- **Built-in web interface** — configuration and firmware updates
- Compatible with apps consuming TCP/UDP NMEA data streams

## Firmware & Updates

Updated via the web interface. Always run the latest firmware —

## Common Use Cases

- Existing wireless installations built around the W2K-1
- Wireless viewing and logging of NMEA 2000 data

## Troubleshooting

| Symptom | Likely cause | Resolution |
|---|---|---|
| No data over Wi-Fi | Backbone not powered/terminated | Check NMEA 2000 power and termination |
| Logging/web UI issues | SD card full or wrong format | Use FAT32 ≤32 GB; see [SD Card Guidance](../faq/faq-1.md) |
| Card size looks small | Decimal vs binary sizing | Expected, not a fault |
