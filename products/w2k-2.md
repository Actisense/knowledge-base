## Overview

The W2K-2 is Actisense's NMEA 2000 to Wi-Fi gateway. It connects directly to an NMEA 2000
backbone and makes the network's data available over Wi-Fi and Ethernet, allowing chartplotter
apps and custom software running on phones, tablets, and computers to receive live vessel data
without a wired connection. It also supports onboard logging to an SD card.

## Key Features

- NMEA 2000 to Wi-Fi and Ethernet gateway
- Serves data to multiple clients simultaneously
- Onboard data logging to SD card
- Built-in web interface for configuration and status

## Connections & Interfaces

- **NMEA 2000:** Micro-C drop connection to the backbone (supplies power and data)
- **Network:** Wi-Fi (access point and/or client mode) and wired Ethernet
- **Storage:** SD card slot for logging — see [SD Card Guidance](../faq/faq-1.md)
- **Power:** Powered from the NMEA 2000 backbone.

## Getting Started

1. Connect the W2K-2 to a spare drop on your NMEA 2000 backbone.
2. Confirm the backbone is powered and correctly terminated.
3. Join the device's Wi-Fi network (or connect it to your onboard network) and open its web interface.
4. Configure output formats/ports for your chartplotter app or software.

## Software & Tools

- **Built-in web interface** — configuration, network settings, and firmware updates
- Compatible with NMEA 2000-aware apps and Actisense tools that consume TCP/UDP data streams

## Firmware & Updates

Firmware is updated through the device's web interface. Always run the latest firmware —
see [actisense.com/downloads](https://actisense.com/downloads/?type=&products=.pro-61445).

## Common Use Cases

- Wirelessly viewing instrument, GPS, engine, and AIS data on a tablet
- Logging a full NMEA 2000 session to SD for later analysis
- Feeding vessel data to a custom onboard application over the network

## Troubleshooting

| Symptom | Likely cause | Resolution |
|---|---|---|
| No data over Wi-Fi | Backbone not powered / not terminated | Check NMEA 2000 power and termination |
| Logging stops or web UI unresponsive | SD card full or wrong format | Use FAT32 ≤32 GB; see [SD Card Guidance](../faq/faq-1.md) |
| Reported card size smaller than labelled | Decimal vs binary sizing | Expected behaviour, not a fault |
